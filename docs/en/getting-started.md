# Getting started

> Tiếng Việt: [docs/vi/getting-started.md](../../docs/vi/getting-started.md)

## Prerequisites

- `bash` 4 or newer.
- `python3`, for custom agents (`scripts/load_skill.py`) and the test suite.
- `make`, optional — only for the `make` shortcuts.

Nothing else. The repo has no runtime dependencies.

## Install

One command:

```bash
bash /path/to/pstack-universal/scripts/install.sh /path/to/your-project
```

It copies `AGENTS.md`, `.ai/` and `scripts/` into the project and runs
`scripts/sync.sh` there, so the per-agent rule files are generated in one step.

| Option | Effect |
|---|---|
| `--force` | Merge the source `AGENTS.md`, `.ai/` and `scripts/` over the target's, then re-run the sync |
| `--dry-run` | Print what would happen, change nothing |
| `--no-sync` | Copy the files but skip generating the agent rule files |

Without `--force` the script refuses to touch an existing install, so a second
run against the same project is safe and does nothing. With `--force` the source
files replace their counterparts and everything else is left alone;
`.ai/conventions.md` is not in the source, so it survives the update.

<details>
<summary>Manual install</summary>

1. Copy `AGENTS.md`, `.ai/` and `scripts/` into the project root.
2. Run `bash scripts/sync.sh`.

</details>

## Fill in Project overrides

`AGENTS.md` ends with a **Project overrides** section. These take priority over
everything above them except the hard rules. Put the real commands for this
project there:

```
- Build: `npm run build`
- Test: `npm test`
- Lint/typecheck: `npm run lint`
```

`/verify` reads this section to decide what to run. If it is left blank, the
agent has to guess from `package.json`, `Makefile`, `pyproject.toml`, `Cargo.toml`
or CI config.

## Regenerate after every edit

Edit `AGENTS.md`, never the generated files. Then:

```bash
bash scripts/sync.sh
```

To check without writing — in CI, for example:

```bash
bash scripts/sync.sh --check     # exits 1 and names any stale file
```

## Verify the install

```bash
bash scripts/test.sh
```

It covers `install.sh` behaviour and the `load_skill.py` CLI. An installed
project has no `docs/`, so the link check is skipped there rather than failed.

When you are working in the pstack-universal repository itself, `make check` runs
the same suite plus the generated-file drift check.

## What your agent now sees

Each tool reads its own file, generated by the sync: `CLAUDE.md` for Claude
Code, `.cursor/rules/pstack.mdc` for Cursor, `.clinerules` for Cline,
`.roorules` for Roo Code, `.windsurfrules` for Windsurf,
`.github/copilot-instructions.md` for Copilot, and `AGENTS.md` itself for Codex
and anything else that reads it. The full table, with notes, is in
[how-it-works.md](how-it-works.md#what-the-sync-generates).

Confirm it worked by asking for something small, for example `/verify`.
